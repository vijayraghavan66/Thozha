# Cloudflare cost and usage estimate

Current design targets the Cloudflare Workers Free plan with SQLite-backed Durable Objects. Cloudflare's current official limits list Workers Free at 100,000 requests/day and 10 ms CPU/request. Durable Objects on Workers Free are SQLite-only and include 100,000 DO requests/day, 13,000 GB-s/day, 5 million row reads/day, 100,000 row writes/day, and 5 GB total SQLite storage. Free-tier excess fails rather than automatically billing. Sources: [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/), [Durable Objects pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/).

For one simulated host and one phone, a sparse task/approval workflow should stay far below those quotas: a few HTTPS requests per task plus bounded queue writes. Persistent WebSocket sessions should use Durable Object WebSocket Hibernation to avoid idle duration charges; the DO remains the authoritative queue, and the client can fall back to signed polling. No paid plan, service, domain, R2, or database is configured. Before any deployment, inspect live Cloudflare billing and free-tier quotas; these values can change.
